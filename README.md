# RuTAG Groundwater Management App

Flutter-based mobile application for groundwater monitoring and prediction.

## Features
- Real-time groundwater level monitoring
- ML-powered predictions
- Bluetooth sensor integration
- Multi-station data visualization
- Admin and user roles

## Tech Stack
- **Framework**: Flutter
- **State Management**: Provider
- **Backend**: Firebase
- **ML Integration**: Flask API
- **Sensors**: Bluetooth-enabled water level sensors

## Setup

```bash
# Install dependencies
flutter pub get

# Run on device
flutter run

# Build APK
flutter build apk --release
